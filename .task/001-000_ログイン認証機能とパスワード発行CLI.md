# ゴール: ログイン認証機能とパスワード発行 CLI

## 概要

Web アプリケーションにログイン認証機能を追加し、管理者（`admin`）とゲスト（`guest`）の2つのロールによるアクセス制御を導入する。
また、CLI から各ユーザーのパスワードを安全かつ簡易に発行・再発行（上書き）できるようにする。

## 利用者と権限

| ユーザー名 | 役割 | 利用可能な機能 | 制限事項 |
|---|---|---|---|
| `admin` | 管理者 | 全機能（変換、ストリーミング変換、確定保存、ロジック更新、ロジック表示） | なし |
| `guest` | ゲスト | 変換機能（変換、ストリーミング変換、現行ロジック表示） | 確定保存・ロジック更新は不可（記録も更新もされない） |

- 許可するユーザー名は `admin` と `guest` の2名のみ。
- 未ログインのユーザーは変換やロジック関連の API を利用できず、ログイン画面へ誘導される。

## パスワード発行 CLI

- `romaji issue-password <username>` コマンドでパスワードを発行する。
- 指定可能なユーザー名は `admin` または `guest` のみ。
- パスワードは内部で必要十分な長さ（暗号学的に安全なランダム文字列）を自動生成する。
- パスワード再発行は単純な上書き（古いパスワードの入力確認なし）。
- 発行された平文パスワードは CLI の標準出力に表示され、ハッシュ化されて永続化される。

## セキュリティ・データ管理

- パスワードはソルト付きハッシュ（PBKDF2-HMAC-SHA256 等）で保存し、平文では保存しない。
- 認証データ（パスワードハッシュ、署名鍵）は `data/auth/` に保存し、Git の追跡対象外（`.gitignore`）とする。
- 認証セッションは HttpOnly Cookie またはトークンで管理し、セキュアに維持する。
