# ゴール: ローマ字→日本語変換 Web アプリ

## 概要

ローマ字入力を LLM で自然な日本語文に変換する、自分専用の Python Web アプリを作る。  
単純なかな変換ではなく、文脈・表記を踏まえた整形を行う（参考: `sample.txt`）。

## 成果物イメージ

- 左ペインに入力したままのローマ字、右ペインに変換結果を表示する Web UI
- 入力が途切れたら自動で変換する（debounce）
- 変換ロジックは LLM への指示文として持ち、人間の修正例から改訂できる
- OpenAI 互換 API（OpenRouter 等）経由で LLM を呼び出す

## 利用前提

- 利用者は自分のみ（デスクトップ／ノートなど複数端末の交互利用あり）
- 当面は localnet。外出先は SSH ポートフォワードでアクセス
- 認証・公開向け HTTPS は初期スコープ外

## 画面と操作

| 操作 | 内容 | 永続化 |
|------|------|--------|
| 入力・自動変換・右側の編集 | セッション／ブラウザ内のみ | しない |
| 確定／保存 | 学習・履歴用に入出力を記録 | する |
| ロジック更新 | 蓄積した確定例から変換指示文を改訂（確認なしで即反映） | する |

- 「確定／保存」と「ロジック更新」は別操作とする
- 未変換の下書きを端末間で共有することはしない

## LLM 役割分担

| 役割 | 用途 | モデル方針 |
|------|------|------------|
| 変換実行 | debounce による高頻度変換 | 軽量・低遅延。候補はあるが、**ある程度完成後に実測して確定** |
| ロジック改訂 | 明示ボタン押下時のみ | 高度モデル。初期候補: `openai/gpt-5.6-terra`（品質優先の代替: `anthropic/claude-fable-5`） |

変換実行の暫定候補（実測前の参考）:

- `google/gemini-3.1-flash-lite-preview`
- `google/gemini-3-flash-preview`
- `openai/gpt-5.6-luna`

## 変換ロジックの版管理

- ロジック更新は確認なしで現行版を差し替える
- 過去版に戻せるようにする（CLI 可）
- 確定保存時は、可能ならその時点のロジック版も記録する

## 設定・データ

| 内容 | 場所 | Git |
|------|------|-----|
| API キー本体 | `.env` | コミットしない |
| モデル、base URL、キーの環境変数名、bind など | TOML | コミットしてよい |
| 変換ロジック・確定例など | TOML 等 | 方針に応じてコミット可 |

- TOML で `api_key_env` のように、キーを読む環境変数名を指定する
- **bind アドレス／ポートは TOML 必須。コード側デフォルトなし**（未設定なら起動失敗）
- Ollama / LM Studio 等でよく使うポート（例: `11434`, `1234`, `8080`, `8000`, `7860`, `5000`, `3000`）は避ける
- ドキュメント上の推奨例（必須値ではない）: `127.0.0.1:18765`

## テスト

- 統合テストで実 API 呼び出しを行ってよい
- 変換モデル確定のための実測も、完成に近い段階で実施する
