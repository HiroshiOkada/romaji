# ゴール: 変換結果コピーとクリアボタン

## 概要

Web UI に、変換結果をクリップボードへコピーし、その後入力欄と変換結果欄をクリアする単一のボタンを追加する。
変換結果を別アプリで利用した後、続けて次の入力を行うまでの一連の操作（コピー → 欄の消去）をワンクリックで行えるようにする。

## 要件

- ボタンは 1 つで、次の動作を行う:
  1. 変換結果欄（編集後の内容を含む）のテキストをクリップボードへコピーする
  2. 成功したら入力欄と変換結果欄をクリアする
- ボタンのラベルは「コピーして次へ」とする。
- 変換結果が空の場合はコピーせず、ステータス欄にその旨を表示する。
- コピーに失敗した場合は欄をクリアせず、エラーをステータス欄に表示する。
- `admin` / `guest` の両ロールで利用可能とする（データの保存・更新は行わないため）。
