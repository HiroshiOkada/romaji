# 004-000: ファビコンの追加

## 作業目標

ブラウザのタブやブックマークで `romaji` アプリをひと目で識別できるよう、シンプルでわかりやすいファビコンを追加する。

## 要件

- アプリの配色（ティール `#0f6a5a` と明るいクリーム色 `#f7fffc`）に調和し、ローマ字・日本語変換アプリであることが直感的にわかるシンプルな SVG ファビコン（`static/favicon.svg`）を作成する。
- 小さいサイズ（16×16 / 32×32）でも視認性が高く、OS・フォント環境に依存しないベクターパスで描画する。
- `static/index.html` の `<head>` に `<link rel="icon">` を追加する。
- ブラウザからの `/favicon.ico` リクエストに対しても 404 にならないよう、`src/romaji/app.py` でファビコンを返すエンドポイントを用意する。
- 単体テストを追加し、既存のテストを含めて全テストが通ることを確認する。
