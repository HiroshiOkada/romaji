# 003-001: 実装計画 — 設定ファイルの自動再読み込み

ゴール: `.task/003-000_設定ファイルの自動再読み込み.md` を参照。

## チェックリスト

- [x] `config.py` に mtime 監視型の `ConfigCache` を追加する
  - config.toml と `config.toml と同階層の .env` の `st_mtime_ns` の組をステップとして保持
  - 変更検知で `load_config()` を再実行。再読込時は `load_dotenv(override=True)` で API キー更新にも追随
  - 再読込失敗時（ConfigError 等）は前回値で続行し、logging.warning を出す（初回はそのまま失敗させる）
  - スレッドセーフ（FastAPI の sync エンドポイントはスレッドプールで動くため Lock で保護）
- [ ] `app.py` を `lru_cache` から `ConfigCache` に置き換え、`run()` の手動キャッシュクリアを撤去する
- [ ] 単体テスト `tests/test_config_cache.py` を追加する
  - config.toml の更新を検知して再読込される
  - .env の更新を検知して API キーが差し替わる
  - 不正なファイル更新では前回値を返し落ちない
- [ ] 全テストを実行し、README に新しい挙動を追記する
- [ ] main にマージする
