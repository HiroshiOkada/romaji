# 003-000: 設定ファイルの自動再読み込み

## 作業目標

`config.toml`（および `.env`）をアプリの再起動なしに反映できるようにする。

現在は `get_config()` が `lru_cache` でキャッシュしており、設定変更のたびに
`sudo systemctl restart romaji.service` が必要。変換リクエスト時など、
リクエスト処理の途中で設定ファイルの mtime をチェックし、更新があれば
自動で再読込する。リアルタイム性は不要で、次のリクエストから反映でよい。

##完了の定義

- config.toml / .env を編集したあと、プロセス再起動なしで翌リクエスト以降に新設定が使われる
- 設定ファイルが一時的に不正な場合も、プロセスは落ちず、前回の正常な設定を使い続ける
- `[server] host/port` は uvicorn 起動時に bind するため再起動が必要であることを文書化
- 単体テスト・全テストが通る
